Programming Job Simulator

A simulation game where users can experience realistic working life as a programmer by completing algorithm tasks and collaborating with other coworkers.

View Project
Game Description


Work on programming tasks. Some tasks may require collaboration with other NPCs.

Attend the meeting. Discuss programming solutions to other NPCs or solve business problems together.

Have lunch/dinner with the team together. Socialize with other co-worker NPCs to improve relations.

Each of the co-workers has their unique schedule, working style, and behaviors towards each other. Co-worker NPCs will follow their working schedules based on time, workload, etc, using decision trees.

Users can interact with other co-workers to help or prioritize tasks. Users can give commands to any co-workers, which can temporarily change their working schedules.

This project is powered by NVIDIA.
